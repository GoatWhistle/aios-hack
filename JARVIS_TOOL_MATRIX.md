# Матрица покрытия инструментов Jarvis

Сверено с реестром backend `tool_specs()` и `definition()` 27.09.2026. В реестре 25 инструментов. Аргументы перечислены из JSON Schema; необязательные поля отмечены `?`. Карточка и маршрут указаны из регистрации и `ROUTE_BY_CARD`; «нет маршрута» означает, что карточка остаётся в ответе Jarvis.

Выдача ограничена схемой: `rank_wells.limit` — 1–10, `well_series` — control_step 0–224, включая границы подсветки. Публичный dispatch отклоняет выход за эти пределы.

| Инструмент | Для какого вопроса | Аргументы | Карточка | Действие/маршрут |
|---|---|---|---|---|
| `well_snapshot` | Состояние скважины на шаге: режим, дебиты, давление, ЧДД и спарклайн | `well`, `step?` | `well` | field / projection, выбранная скважина и шаг |
| `well_series` | Ряд дебита, закачки, обводнённости или давления | `well`, `metric` (обязательны), `from_step?`, `to_step?`, `window?` (ровно две границы внутри диапазона) | `series` | history / table; контекст шага берётся из ряда |
| `compare_wells` | Фактическое сравнение двух скважин на одном шаге | `a`, `b` (обязательны), `step?`, `run_id?` | `well-comparison` | нет маршрута |
| `field_metrics` | Метрики фонда на шаге | `step?` | `metric` | overview / fund |
| `field_events` | События фонда за диапазон шагов | `from_step?`, `to_step?`, `types?` | `event-strip` | history / matrix; первое событие |
| `rank_wells` | Рейтинг скважин по ЧДД, обводнённости, дебиту или закачке | `by` (обязателен), `order?`, `limit?`, `step?` | `well-list` | money / rank; первая скважина |
| `connectivity` | Измеренные связи скважины и соседи | `well` (обязателен), `limit?`, `min_weight?` | `field-map` | field / maps; первая скважина |
| `find_patterns` | Диагностические паттерны по фонду или скважине | `well?`, `pattern?`, `limit?` | `pattern` | field / projection; первая находка |
| `explain_decision` | Записанное объяснение решения на шаге | `well`, `step` (обязательны в схеме; обработчик умеет контекстный fallback) | `rule` | decisions / rules |
| `decision_journal` | Журнал сработавших правил, предложений и итоговых команд | `well?`, `step?`, `run_id?` | `rule` | decisions / rules или run-backed панель |
| `rule_impact` | Измеренный вклад правила по ablation | `rule?` | `rule` | decisions / rules |
| `compare_scenarios` | Сравнение двух сценариев витрины | `a?`, `b?` | `compare` | money / comparison, сторона B |
| `explain_term` | Определение термина, формула, единицы и источник | `query` (обязателен), `lang?` | `glossary` | переход к месту термина, если оно индексировано |
| `platform_guide` | Справка об экране и его управлении | `query` (обязателен), `workspace?`, `view?`, `lang?` | `guide` | маршрут, только если он валиден и документирован |
| `run_status` | Статус прогона, допуск по записанным проверкам и ЧДД | `run_id?` | `run-status` | money / comparison; нарушение открывает run/well/step |
| `submission_summary` | Наличие и сверка сдаваемого пакета | `run_id?` | `submission` | money / comparison |
| `search_docs` | Поиск по проектным документам и базе знаний | `query` (обязателен), `k?`, `scope?` | `doc` | нет; локальные ссылки в источниках |
| `system_map` | Компоненты AIOS и потоки данных | `focus?`, `depth?` | `system-map` | маршрут выбранного узла, если он задан |
| `system_status` | Чемпион, последний прогон, выбранный сценарий и находки | нет | `status-board` | money / comparison |
| `run_history` | Список прогонов и зарегистрированных сценариев | `limit?`, `status?` | `run-list` | money / comparison |
| `run_detail` | Манифест, проверки и заключение по прогону | `run_id?` | `run` | money / comparison |
| `compare_runs` | Сопоставимость и арифметическая разница двух прогонов | `a?`, `b?` | `compare` | money / comparison; переход к run B, если это прогон |
| `case_constraints` | Лимиты, остановки и инфраструктура кейса с источниками | `case?` | `constraints` | money / constraints |
| `council_step` | Распределение квот и решение совета на шаге | `step?`, `group?`, `well?` | `council` | decisions / council; выбранная скважина |
| `physics_report` | Физическая допустимость прогона и статусы инвариантов | `run_id?` | `physics` | money / comparison |

## Данные и отказ при их отсутствии

| Инструмент | Основные доступные данные | Если данных недостаточно |
|---|---|---|
| `well_snapshot` | Ряд измерений выбранного сценария на одной дате | Неизвестная скважина/шаг или отсутствующий сценарий дают ошибку; отсутствующее поле остаётся пустым, не превращается в ноль |
| `well_series` | Временной ряд метрики из выбранного сценария и даты витрины | Неизвестные скважина/метрика, диапазон вне горизонта или пустой ряд дают объяснимый отказ |
| `compare_wells` | Состояния обеих скважин на общем шаге и измеренное ребро графа связности | Одинаковые/неизвестные скважины или недоступный шаг отклоняются; отсутствие ребра показывается как незаписанная связь |
| `field_metrics` | Агрегированные метрики выбранного сценария и даты | Отсутствующий сценарий/шаг/обязательная метрика отклоняется |
| `field_events` | Рассчитанные события ряда фонда за выбранный интервал | Некорректный интервал отклоняется; отсутствие событий возвращает пустой список, а не выдуманное событие |
| `rank_wells` | Сортируемые значения выбранной метрики по фонду | Неизвестная метрика, шаг вне горизонта или отсутствие значений отклоняются |
| `connectivity` | Граф измеренных связей и метаданные источника | Неизвестная скважина отклоняется; порог без рёбер возвращает пустую выдачу |
| `find_patterns` | Наблюдения сценария и каталог диагностических правил | Недоступный сценарий/паттерн отклоняется; отсутствие находок возвращает конкретный `ToolFailure` с причиной |
| `explain_decision` | Записанные сработавшие правила и команды сценария | Нет записи для выбранной пары скважина/шаг — типизированный отказ без реконструкции причины |
| `decision_journal` | Индексированные run-backed факты выбора, предложения и команды | Не найден run-журнал или требуемая пара скважина/шаг — отказ с указанием отсутствия записи |
| `rule_impact` | Политика правил и результаты ablation, если они импортированы | Неизвестное правило отклоняется; без измерения uplift результат явно помечается «не измерено» |
| `compare_scenarios` | Ряды метрик двух сценариев витрины | Неизвестный/одинаковый сценарий или отсутствие общего сравнимого ряда отклоняется |
| `explain_term` | Терминологический индекс знаний и ссылки на источник | Не найденный термин явно помечается как общее объяснение, не как цитата из индекса |
| `platform_guide` | Индекс справки по интерфейсу и разрешённым маршрутам | Неизвестный экран/запрос отклоняется; действие не строится без подтверждённого маршрута |
| `run_status` | Реестр прогонов, манифест, OPM/validation и constraints артефакты | Неизвестный прогон отклоняется; отсутствующие поля/проверки остаются `not_recorded`/`unknown` |
| `submission_summary` | Пакет сдачи, claimed NPV и сверка с манифестом | Нет пакета — карточка явного отсутствия; неполный или несовпадающий пакет не объявляется валидным |
| `search_docs` | Индекс документов и knowledge chunks | Пустой/неподдержанный запрос или недоступный индекс отклоняется; источники без безопасной ссылки остаются без URL |
| `system_map` | Граф компонентов и их документированных связей | Неизвестный узел или повреждённая карта отклоняется; компонент не создаётся по догадке |
| `system_status` | Выбранный сценарий, отдельно champion/latest run, диагностика и нарушения latest run | Недоступность отдельного источника передаётся своим статусом/причиной, а не пустым успешным результатом |
| `run_history` | Манифесты из настроенных каталогов и реестр сценариев | При полном отсутствии прогонов/реестра возвращается конкретный отказ с просмотренными каталогами |
| `run_detail` | Манифест, происхождение, проверки, журнал и response bundle | Неизвестный run отклоняется; зарегистрированный пакет без манифеста выдаёт ограниченное заключение с явным отсутствием источника |
| `compare_runs` | Два run detail и пересечение зафиксированных условий/экономических артефактов | Нет идентифицируемой пары или обязательных оснований сопоставимости — отказ/непроверяемый статус, без смешения NPV источников |
| `case_constraints` | Файл ограничений выбранного кейса и источники полей | Неизвестный кейс, отсутствующий или некорректный файл отклоняется; лимиты не выводятся из отсутствующего файла |
| `council_step` | Иерархический журнал решений `hierarchy.json` для control_step | Нет журнала или строки шага — `no-council-step`; нельзя восстановить решение из итоговой команды |
| `physics_report` | Physics JSON отчёты в validation выбранного прогона | Нет прогона/physics-отчёта — типизированный отказ, а не допуск по умолчанию |

Неподдержанный инструмент или аргументы вне схемы отклоняются до вызова обработчика. Матрица описывает фактические ветви в коде; отдельные реальные успешные сценарии нужны для каждого источника, особенно для артефактов, которых нет в текущей витрине. Reader каждого зарегистрированного типа карточки проверяется по fixture JSONL.

## Остаток аудита

Матрица теперь фиксирует контракт, источник данных и явно предусмотренный отказ по всем 25 инструментам. Она не заменяет проверку каждого сочетания входов на реальных данных. Остались сценарные проверки единиц/дат и навигации по каждому инструменту, а также недостающие реальные артефакты и интеграционные отказы. Матрица выявила и закрыла пропущенный frontend renderer для `submission`.

Отображение единиц и точных дат проходит через общий локализованный UI formatter для карточек Jarvis. В API/payload остаются исходные unit tags и ISO-даты; временные оси графиков сохраняют компактную подпись месяца/года. Полный перебор полей и числовых примеров всех 25 карточек ещё не выполнен.
