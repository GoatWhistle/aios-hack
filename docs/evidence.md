# Доказательства

> Каждое утверждение проекта с градацией по тому, **как** оно известно: измерено командой,
> удерживается машинной проверкой, прочитано в артефакте, наблюдалось однажды или принято
> на веру. Сильнейший результат здесь — холодный повтор, воспроизведший ЧДД бит в бит.
> Слабейший — метрики качества суррогата, у которых в этом репозитории нет опоры в данных.
> Когда защитимы две градации, ставится нижняя.

**Читайте это, если хотите понять, какой вес выдерживает каждое число** · **Рядом:**
[границы](limitations.md) · [проверка](verification.md) · [суррогат](surrogate.md)

---

## Как градуируются утверждения

| Статус | Что означает |
|---|---|
| **Измерено** | Число получено прогоном и лежит в артефакте репозитория; путь указан рядом |
| **Удерживается** | Машинная проверка падает, когда свойство перестаёт выполняться; проверка названа |
| **Прочитано** | Значение прочитано в конфиге или артефакте без отдельного измерения |
| **Наблюдалось** | Видели в работе, возможно однажды; не обобщается |
| **Из текста** | Есть только в прозе документа; данных или кода, подтверждающих число, в репозитории нет |
| **Принято на веру** | Обосновано рассуждением, но не измерено, и так и помечено |
| **Ложно, и сказано, что ложно** | Свойство, которого читатель мог бы ожидать, а системы у него нет |

## Что показал холодный повтор

Самый сильный результат проекта, потому что он воспроизводимый и точный.

Из чистого клона был заново посчитан кандидат `candidate-005`. Файл
[`artifacts/final-readiness-20260909/cold-repeat/candidate-005/economics/result.json`](../artifacts/final-readiness-20260909/cold-repeat/candidate-005/economics/result.json)
содержит:

| Поле | Значение |
|---|---|
| `measured_npv` | 1464123030.4381707 |
| `npv_methodology` | 1464123030.4381707 |
| `sound` | `true` |
| `economics_config_hash` | `44a24e2ac0c700ad50228a414c56235c948a4edea30a0cca34d0a2d6186ef2af` |
| `methodology_version_hash` | `74f2872e1d1e52b0774454e92ebcf0030701c6fe21845de01a1b33e6917f984c` |
| `source_response_hash` | `361a18dae4550de75afaa1fb7511b44023793889fcccc80091cf4c179fd4a6d2` |
| `source_run_id` | `20260909T201028-4ef81589f96f` |

Два числа совпадают до последнего разряда: ЧДД, измеренный на отклике, и ЧДД, посчитанный
по методике. Хеши конфигурации экономики и версии методики совпадают с теми, что записаны
у `candidate-005` в [`evaluations.json`](../artifacts/final-readiness-20260909/evaluations.json).

**Чего это не доказывает.** Воспроизводимость расписания — не доказательство его
оптимальности и не перенос на другой кейс.

## Чего нет в данных

Названо прямо, чтобы никто не рассчитывал на несуществующий файл.

- **out/metrics-full-pipeline.json** — отчёт, который печатает Spearman, precision@k,
  MAE и P95 относительной ошибки. На него ссылается `RELEASE_SURROGATE_20260906.md`;
  на диске его нет. Инструмент, который его строит, — в
  [`surrogate_metrics_report.py`](../backend/interfaces/cli/surrogate/tools/surrogate_metrics_report.py).
- **Датасет из 700 прогонов** — в git не хранится по замыслу.
- **Веса суррогата** — ставятся отдельно; в репозитории только указатель и хеши.
- **Журнал генерации финального кандидата** — отсутствует, поэтому происхождение решений
  именно сданного плана объяснить нельзя.
- **Собранный пакет сдачи** — появляется только после `aios run submit`.

## Метрики Джарвиса

Единственная серия, которую можно назвать измерением, а не наблюдением: 20
последовательных запросов через веб-прокси.

| Величина | Значение |
|---|---|
| Завершились `done` без ошибки | 20 из 20 |
| Вернули карточку | 19 из 20 (один неоднозначный вопрос запросил уточнение метрики) |
| Первая карточка, медиана / P95 | 4,43 с / 9,76 с |
| Полный ответ, медиана / P95 / максимум | 12,50 с / 33,36 с / 44,38 с |

Это серия на одной локальной машине при одном состоянии внешнего шлюза. Она не измеряет
отрисовку в браузере пользователя и ничего не гарантирует при другом балансе ключа или
сетевой нагрузке: в этой сессии тот же шлюз отвечал `HTTP 402`.
