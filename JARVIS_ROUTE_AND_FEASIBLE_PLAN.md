## Цель и границы

Довести до проверенного результата две задачи:

1. Непрерывный пользовательский маршрут в локальном браузере: выбор контекста → вопрос → основания → график/связи → уточнение → допуск → экспорт → восстановление истории.
2. Новый кейс через Джарвиса: черновик → подтверждение → поиск → проверка найденного расписания настоящим OPM → допустимый результат с доступными источниками.

Выполнение начинается отдельной задачей после этого планирования. Все галочки ниже относятся к будущему выполнению; результаты предыдущих проверок их не закрывают.

Работы ограничены этими двумя маршрутами и исправлением дефектов, которые мешают их пройти. Серверный деплой, HTTPS, голос, презентация, репетиции выступления, PDF, поиск конкурентов и расширение каталога функций в этот план не входят. Доступ к отдельному серверу не требуется.

Сданное расписание, веса моделей, алгоритм поиска, правила агентов, пороги OOD и физические ограничения сохраняются. Допустимы исправления передачи контекста, конфигурации runtime, путей, чтения артефактов, UI и связки существующих стадий расчёта. Если причина требует изменения расчётного метода или ограничений, это отдельная задача за пределами данного плана.

## Критерии завершения

| Задача | Что должно быть получено |
|---|---|
| Непрерывный маршрут | Два последовательных успешных прохода на одной зафиксированной сборке. Все действия выполняются через UI; контекст, данные, скачанный файл и восстановленная история проверены. |
| Допустимый новый план | Новый run, созданный из подтверждённого черновика Джарвиса; кандидат получен поиском; именно его расписание проверено OPM на подтверждённых ограничениях; OPM OK, sound=true, ноль блокирующих нарушений, нет проваленных обязательных проверок, сохранён проверенный ЧДД. |
| Результат в интерфейсе | В браузере открываются правильная задача, окончательный статус, заключение и источники. После reload восстанавливается тот же run без повторного запуска. |

Наличие старого допустимого расписания, успех альтернативного режима alternative, прогноз суррогата или один статус completed не закрывают задачу нового допустимого плана. Превосходство по ЧДД над базой не является критерием этой задачи.

- [ ] Проверенный ЧДД конечен и рассчитан по сохранённому отклику; predicted и verified явно разделены.
- [ ] Карточка Джарвиса и заключение показывают этот run и записанный допуск без предупреждений, которые скрывают существенную ошибку.

**Готово, когда:** другой человек может открыть сохранённые источники и проверить, почему именно этот новый план признан допустимым для указанного кейса.

Если допустимый кандидат не получен в обозначенных пределах, задача B остаётся **незавершённой**. Итог должен содержать выполненные попытки, причины отказов и точную зависимость: отсутствующие данные, ошибка интеграции либо ограничение неизменённого расчётного метода. Последний случай требует отдельного решения о расширении задачи, а не ослабления проверок в рамках этого плана.

После выполнения создать один отчёт в каталоге доказательств и дать на него ссылку из этого плана:

- Версия исходников/сборки и условия проверки.
- Таблица A-01…A-05, B-01…B-07: пройден / не пройден / блокирован, с доказательством для каждой строки.
- Оба непрерывных браузерных прохода, времена и скачанные заключения.

**Ожидаемый результат:** воспроизводимый маршрут пользователя и один новый план, действительно прошедший поиск и OPM-проверку в неизменённых условиях выбранного кейса.
